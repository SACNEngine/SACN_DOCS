# 06 — 播放预览

## 工作方式

```
Animation Window ▶ 按钮
  → DispatcherTimer 60fps
  → Stopwatch 计算实际帧间隔
  → 每帧 Apply(currentTime):
      ① 从 AnimationClipBuilder 求值 Position/Rotation/Scale
      ② 直接设 Entity.Transform
      ③ 场景视图实时更新
```

## 播放控制

| 按钮 | 行为 |
|------|------|
| ▶ | 保存当前姿态 → 开始播放 |
| ⏸ | 暂停（保持当前姿态） |
| ⏹ | 停止 → 恢复原始姿态 |

## 时间推进

- 使用 `Stopwatch` 计算实际 delta time
- `DispatcherTimer` 作为 60fps 的 tick source
- 时间到达 Duration 后自动循环

## 时间滑块

拖滑块或点击 Dopesheet → `CurrentTime` setter 立即调用 `Apply()` → 实体跳转到该帧姿态。不点播放也能看到实体变化。

## 与 Asset Preview 的区别

| | Animation Window ▶ | Asset Preview |
|---|---|---|
| 驱动方式 | 直接改 Transform | 引擎 AnimationProcessor |
| 作用范围 | 编辑中的实体 | 独立预览场景 |
| 用途 | 编辑时预览 | 资产查看 |
