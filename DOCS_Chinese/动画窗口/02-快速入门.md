# 02 — 快速入门

## 5 分钟创建第一个动画

### Step 1: 选中实体

场景中点击任意 Entity（正方体、球体、角色...）

### Step 2: 打开动画窗口

**Ctrl+F12** → 底部出现动画窗口。顶部黄色文字显示选中实体名。

左侧 Properties 出现 3 行：Position / Rotation / Scale。

### Step 3: 设置关键帧

| 操作 | 方法 |
|------|------|
| 拖动时间到 0s | 点时间轴 |
| 移动实体 | 场景中用 Gizmo 拖 |
| **+Key** | 手动拍快照 |
| 拖动时间到 2s | 点时间轴 |
| 移动实体 | 场景中拖 |
| **+Key** | 拍快照 |
| 拖动时间到 4s | 同上 |
| 移动实体 | 同上 |
| **+Key** | 同上 |

### Step 4: 预览

- 点击 **▶** → 实体按关键帧运动
- 点击 **⏹** → 停止，实体恢复原位
- 或**手动拖时间滑块** → 实体跟随当前帧姿态

### Step 5: 保存

- 点击 **💾** → 选择项目 `Assets/` 目录
- 文件名：`MyAnim.sdanimclip`
- Asset View 自动刷新显示

### 工具栏速查

| 按钮 | 功能 |
|------|------|
| ▶ | 播放 |
| ⏸ | 暂停 |
| ⏹ | 停止（恢复原位） |
| ●REC | 录制模式（自动检测变化） |
| +Key | 手动添加关键帧 |
| +Evt | 添加动画事件 |
| ↩ | 撤销 |
| ↪ | 重做 |
| 📂 | 加载动画 |
| 💾 | 保存动画 |
