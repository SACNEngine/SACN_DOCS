# 07 — 保存与加载

## 保存 (.sdanimclip)

### 操作

1. 💾 点击保存
2. 选择项目 `Assets/` 目录
3. 输入文件名（如 `WalkAnim`）

### 输出文件

| 文件 | 格式 | 用途 |
|------|------|------|
| `WalkAnim.sdanimclip` | YAML | Stride 资产（Asset View 显示） |
| `WalkAnim.sdclip.json` | JSON | 运行时直读（PlayAnimationClip） |

### 资产注册

保存后自动：
1. 扫描匹配的 Package
2. 调用 `Package.LoadTemporaryAssets()` 重新扫描磁盘
3. 新增 `AssetItem` 到 `Package.Assets`
4. 调用 `CheckConsistency()` 触发 UI 刷新
5. Asset View 立即显示

### YAML 格式

```yaml
!AnimationClipAsset
Duration: 5.0
Curves:
  - Path: '[TransformComponent.Key].Position'
    Interpolation: Linear
    Keys:
      - Time: 0.0
        X: 1.0
        Y: 2.0
        Z: 0.0
        ValueType: Vector3
```

## 加载

### 从文件加载

1. 📂 点击加载
2. 选择 `.sdanimclip` 文件
3. 属性、关键帧、事件完整恢复

### 双击 Asset View

1. Asset View 双击 `.sdanimclip`
2. 动画窗口自动打开
3. 数据自动加载

## 编译到运行时

```
.sdanimclip (YAML)
     ↓ AssetFileSerializer.Save
  磁盘文件
     ↓ Asset View 双击
  AnimationClipAssetCompiler
     ↓ 构建 AnimationClip
  ContentManager.Save(url, clip)
     ↓
  Content.Load<AnimationClip>(url) → 运行时可用
```
