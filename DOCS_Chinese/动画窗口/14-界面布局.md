## 各区域详解

### ① 工具栏 (Toolbar)

| 控件 | 名称 | 功能 |
|------|------|------|
| ▶ | **Play** | 播放动画 |
| ⏸ | **Pause** | 暂停播放 |
| ⏹ | **Stop** | 停止并恢复原位 |
| ●REC | **Record** | 录制模式（自动检测变化） |
| 🧅 | **Onion Skin** | 3D 洋葱皮开关 |
| 🎯 | **Pick Entity** | 拾取场景实体 |
| `[EntityName]` | **Target** | 当前录制目标实体名 |
| `t=0.00/5.00s` | **Time Display** | 当前时间 / 总时长 |
| `──●──` | **Time Slider** | 时间滑块 |
| +Key | **Add Keyframe** | 手动添加关键帧 |
| +Evt | **Add Event** | 添加动画事件 |
| ↩ | **Undo** | 撤销 (Ctrl+Z) |
| ↪ | **Redo** | 重做 (Ctrl+Y) |
| 📂 | **Load** | 载入动画 |
| 💾 | **Save** | 保存动画 |

### ② 属性面板 (Properties Panel)

| 区域 | 说明 |
|------|------|
| **Properties** 标题 | 属性列表标题 |
| 🟠 橙色行 | 当前选中属性 |
| **Position** | 根位置 (X/Y/Z) |
| **Rotation** | 根旋转 (X/Y/Z/W) |
| **Scale** | 根缩放 (X/Y/Z) |
| **Hips, Spine...** | 骨骼旋转（如有） |
| **输入框 + + 按钮** | 添加自定义属性 |
| **Events** 标题 | 动画事件列表标题 |
| 事件行 | 事件名 + 删除按钮 |

### ③ Dopesheet 时间线 (Dopesheet Timeline)

| 元素 | 说明 |
|------|------|
| 时间刻度 (0s, 1s...) | 水平秒标尺 |
| 竖线网格 | 每秒一条辅助线 |
| ◆ 灰色菱形 | 普通关键帧 |
| 🔴 粉色菱形 | 洋葱皮：前一个关键帧 |
| 🔵 蓝色菱形 | 洋葱皮：后一个关键帧 |
| 🟠 橙色菱形 | 选中属性的关键帧 |
| ── 红色竖线 (Playhead) | 当前播放头位置 |

### ④ 曲线编辑器 (Curve Editor)

| 元素 | 说明 |
|------|------|
| 网格 | Y轴5条横线 + X轴每秒竖线 |
| Y轴标签 | 值范围 (min ~ max) |
| X轴标签 | 时间范围 (0s, 1s...) |
| 🔴 红色曲线 | X 分量曲线 |
| 🟢 绿色曲线 | Y 分量曲线 |
| 🔵 蓝色曲线 | Z 分量曲线 |
| 🟡 黄色曲线 | W 分量曲线（Quaternion） |
| ● 实心圆点 | 关键帧值点（颜色对应分量） |
| ╱ 半透明切线 | Cubic 切线指示线 |

### ⑤ 插值选择器 (Interpolation Selector)

| 选项 | 效果 |
|------|------|
| **Linear** | 直线连接 |
| **Cubic** | Catmull-Rom 平滑 |
| **Constant** | 台阶式 |

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+F12 | 打开动画窗口 |
| Ctrl+C | 复制关键帧 |
| Ctrl+V | 粘贴关键帧 |
| Ctrl+Z | 撤销 (↩按钮) |
| Ctrl+Y | 重做 (↪按钮) |
