# 03 — 录制模式

## 两种模式

| 模式 | 操作 | 录制方式 |
|------|------|---------|
| **手动** | +Key 按钮 | 点击按钮拍快照 |
| **自动** | ●REC 按钮 | 移动实体自动加帧 |

## 手动录制

1. 拖动时间滑块到目标时间
2. 场景中移动/旋转/缩放实体
3. 点击 **+Key** → 当前姿态记录为关键帧
4. 重复 1-3

## 自动录制（●REC）

1. 点击 **●REC** 进入录制模式
2. 拖动时间滑块到目标时间
3. 场景中移动实体 → **自动创建关键帧**
4. 不需要手动点 +Key
5. 再次点击 ●REC 退出

### 自动录制原理

60fps 检查实体 Transform 变化，epsilon=0.0001：

```csharp
// 每帧检查
if (_rec && TargetEntity != null)
{
    var pos = TargetEntity.Transform.Position;
    if (Math.Abs(_lastPos.X - pos.X) > 0.0001f || ...)
    {
        _lastPos = pos;
        AddKey();  // 自动记录
    }
}
```

### 播放+录制同时

在 ●REC 状态下点 ▶：
- 时间自动推进
- 动画播放
- 移动实体时自动记录新关键帧
- 循环后不会重复录制（播放驱动的变化已被排除）

## 关键帧数据

每次录制记录 3 条曲线：
- `[TransformComponent.Key].Position` → Vector3
- `[TransformComponent.Key].Rotation` → Quaternion
- `[TransformComponent.Key].Scale` → Vector3

## Duration 自动扩展

关键帧时间超过当前 Duration 时，自动 +1s 扩展。
