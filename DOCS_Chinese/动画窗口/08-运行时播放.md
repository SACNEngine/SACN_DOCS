# 08 — 运行时播放（PlayAnimationClip）

## 组件

```csharp
[Display("Animation/Play Animation Clip")]
public class PlayAnimationClip : SyncScript
{
    public string ClipPath;          // 文件名，如 "WalkAnim.sdanimclip"
    public bool PlayOnStart = true;  // 启动时自动播放
    public AnimationRepeatMode RepeatMode = LoopInfinite;
}
```

## 使用方式

1. 选中实体 → Add Component → **Play Animation Clip**
2. **ClipPath** = `"WalkAnim.sdanimclip"`
3. F5 → 动画自动播放

## 文件查找

自动搜索以下路径（从运行目录向上）：

1. 可执行文件同目录
2. 向上到 solution 根的 `Assets/` 文件夹
3. 递归搜索所有 `Assets/` 子目录

## 播放机制

- 直接读 `.sdclip.json` 或 `.sdanimclip` YAML
- 每帧 `Update()` 中求值曲线 → 设 `Entity.Transform`
- 不依赖 `Content.Load<>()` → 不需要资产编译

## 代码调用

```csharp
// 手动控制播放
var player = Entity.Components.Get<PlayAnimationClip>();
player.Play();   // 开始
player.Pause();  // 暂停
player.Stop();   // 停止并归零
```
