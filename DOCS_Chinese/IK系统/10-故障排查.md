# 10 — 故障排查

## IK 完全没有效果

| 可能原因 | 检查方法 | 解决 |
|---------|---------|------|
| 骨骼名不匹配 | 对照 Skeleton.Nodes 精确名称 | 完整复制骨骼名（含大小写、空格） |
| Weight = 0 | 属性面板查看 Chains.Weight | 设为 1.0 测试 |
| 实体无 Skeleton | 添加 IkComponent 但实体无 ModelComponent | 确认模型已导入并挂载 |
| IkComponent 未添加 | 属性面板查看 | Add Component → IK |

## 骨骼名字不匹配

常见错误：
```
✗ "UpperArm_L"     → 实际是 "LeftUpperArm"
✗ "Left Upper Arm" → 实际是 "LeftUpperArm"（无空格）
✗ "leftupperarm"   → 实际是 "LeftUpperArm"（大小写敏感）
✗ "Hand_L"         → 实际是 "LeftHand"
```

**正确做法**：ModelComponent → Skeleton → Nodes 逐个查看，完整复制。

## IK 导致奇怪的弯曲

| 问题 | 原因 | 解决 |
|------|------|------|
| 肘部反弯 | HintPosition 不对 | 调整 Hint 位置，通常设为 Target + 前方偏移 |
| 手臂旋转过度 | Weight 太高 | 降低到 0.5-0.7 |
| 关节抖动 | CCD 迭代太少 | 增加 CcdIterations |
| 根部运动过大 | 用 CCD 而非 FABRIK | 长链换 FABRIK |

## 动画和 IK 冲突

```
如果动画已经定义了手部位置，IK 又改了同一个位置：
  Weight < 1.0 → 动画为主，IK 微调
  Weight = 1.0 → IK 完全覆盖动画
```

## 性能问题

- 多个角色的 IK 同时运行没问题（O(n) 骨骼数）
- 不需要的 Chain 设 `Weight=0` 跳过计算
- FABRIK 3 次迭代通常足够
- CCD 控制在 5-8 次迭代

## 编辑器无 IK 预览

确认 IkComponent 的 Processor 注册了 Preview 模式：
```csharp
ExecutionMode.Runtime | ExecutionMode.Thumbnail | ExecutionMode.Preview
```
