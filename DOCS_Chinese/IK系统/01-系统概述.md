# 01 — IK 系统概述

## 架构

```
每帧渲染管线：
  AnimationProcessor (-500)     → 动画求值骨骼
  AnimatorProcessor (-500)      → 状态机 + IK Pass
  IkProcessor (-499)            → IK 求解修正骨骼
  渲染                          → GPU 蒙皮
```

## 核心组件

### IkComponent

```csharp
// 属性面板 → 添加组件 → 搜索 "IK"
public class IkComponent : EntityComponent
{
    public List<IkChainSetup> Chains { get; }
}
```

### IkChainSetup

```csharp
public enum IkType { TwoBone, LookAt, CCD, FABRIK, MultiAim }

public class IkChainSetup
{
    public IkType Type;             // IK 类型
    public string Bone;             // LookAt/MultiAim 单骨名
    public string RootBone;         // TwoBone/CCD/FABRIK 根骨
    public string MidBone;          // TwoBone 中骨
    public string TipBone;          // TwoBone/CCD/FABRIK 末端
    public Vector3 TargetPosition;  // 世界空间目标
    public Vector3 HintPosition;    // TwoBone 弯曲方向
    public float Weight;            // 0-1 融合权重
    public int CcdIterations;       // CCD/FABRIK 迭代次数
}
```

## 五种 IK 类型速查

| Type | 骨骼数 | 配置骨骼 | 用途 |
|------|--------|---------|------|
| TwoBone | 3 | Root + Mid + Tip | 手臂、腿 |
| LookAt | 1 | Bone | 头部注视 |
| CCD | 多 | Root + Tip | 尾巴、触手 |
| FABRIK | 多 | Root + Tip | 长链快速收敛 |
| MultiAim | 1 | Bone | 武器瞄准 |

## 找到骨骼名字

1. 选中角色实体
2. ModelComponent → Skeleton → Nodes
3. 逐个展开看 Node.Name
4. **必须完整复制，区分大小写和空格**

## 快速配置三步

1. 选中角色实体 → Add Component → **IK**
2. Chains → **+** → 选 Type → 填骨骼名 → 设 TargetPosition
3. F5 或编辑器实时预览
