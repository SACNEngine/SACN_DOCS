# 05 — 曲线编辑器

## 界面

右侧面板。选中左侧属性行 → 显示该属性的曲线。

```
          值轴
           │
    max ───┼────────────────────────
           │    🔴──────🔴
           │   ╱         ╲
           │  ╱           ╲────🔵
    min ───┼────────────────────────
           └── 0s ── 2s ── 4s ─── 时间轴

    🔴 X (红)   🟢 Y (绿)   🔵 Z (蓝)   🟡 W (黄)
```

## 子分量颜色

| 分量 | 颜色 | 说明 |
|------|------|------|
| X | 🔴 红色 | Position.X / Rotation.X / Scale.X |
| Y | 🟢 绿色 | Position.Y / Rotation.Y / Scale.Y |
| Z | 🔵 蓝色 | Position.Z / Rotation.Z / Scale.Z |
| W | 🟡 黄色 | Rotation.W（Quaternion only） |

## 操作

| 操作 | 方法 |
|------|------|
| 拖拽子分量点 | 按住圆点拖 → 只改该分量值 |
| 点击空白 | 添加新关键帧 |
| 右键圆点 | 删除关键帧 |

## 插值类型

底部下拉框：

| 类型 | 效果 |
|------|------|
| **Linear** | 直线连接（默认） |
| **Cubic** | Catmull-Rom 平滑曲线 |
| **Constant** | 台阶式跳变 |

## 网格

Y 轴：5 条横线 + 数值标签（自动缩放）
X 轴：每秒一条竖线 + 时间标签
