# 01 — 动画窗口系统概述

## 架构

```
AnimationWindow (WPF UserControl)
├── ViewModel (AnimationWindowViewModel)
│   ├── AnimationClipBuilder → 曲线数据
│   ├── DispatcherTimer → 播放控制
│   ├── Undo Stack → 撤销/重做
│   └── Save/Load → .sdanimclip 资产
├── Dopesheet (Canvas) → 时间线 + 关键帧菱形
├── Curve Editor (Canvas) → 多彩子曲线
└── Properties Panel → 属性列表
```

## 数据模型

```
Animation Window 数据流:
  实体 Transform
       ↓ snapshot
  _kfv (Dictionary<string, Dictionary<float, object>>)
       ↓
  AnimationClipBuilder (_curves)
       ↓ Build()
  AnimationClipAsset
       ↓ AssetFileSerializer
  .sdanimclip (YAML 资产)
       ↓ 编译器
  AnimationClip → ContentManager → 运行时可用
```

## 属性路径（引擎兼容）

```
[TransformComponent.Key].Position   → AnimationCurve<Vector3>
[TransformComponent.Key].Rotation   → AnimationCurve<Quaternion>
[TransformComponent.Key].Scale      → AnimationCurve<Vector3>
```

与 FBX 导入器生成的路径完全一致。

## 核心文件

| 文件 | 行数 | 作用 |
