# 13 — 故障排查

## 实体不跟随动画

| 可能原因 | 检查 | 解决 |
|---------|------|------|
| 未选中实体 | TargetName 显示 "(select entity)" | 场景中点实体 |
| 无关键帧 | Dopesheet 无菱形 | +Key 添加关键帧 |
| 未点播放 | ▶ 按钮未按下 | 点 ▶ 或拖时间滑块 |

## ▶ 播放不动

| 可能原因 | 解决 |
|---------|------|
| 没有关键帧 | +Key 添加至少一个 |
| Duration=0 | 属性面板设 Duration > 0 |

## 💾 保存后 Asset View 不显示

| 可能原因 | 解决 |
|---------|------|
| 文件在 Assets 文件夹外 | 保存到项目 `Assets/` 下 |
| 未刷新 | 右键 Assets → Reload |
| Stride 文件监控未触发 | 重启项目 |

## .sdanimclip 控制台报错

```
Failed to load asset: assetType is null
```
→ 旧的 JSON 格式文件用了 `.sdanimclip` 扩展名
→ 删除文件，重新从动画窗口保存

## 加载后关键帧为空

| 可能原因 | 解决 |
|---------|------|
| 加载了旧格式 JSON 文件 | 删除旧文件，重新保存 |
| YAML 反序列化失败 | 检查文件是否完整 |

## 双击 .sdanimclip 无反应

→ 检查是否正确编译了最新代码
→ `AssetEditorsManager.OpenAssetEditorWindow` 中有 `AnimationClipAsset` 分支

## 关键帧值看起来不对

| 问题 | 原因 |
|------|------|
| 所有值相同 | 录制时未移动实体 |
| 值跳变 | 关键帧时间重叠 |
| 缩放异常 | Scale 值可能被修改过 |
