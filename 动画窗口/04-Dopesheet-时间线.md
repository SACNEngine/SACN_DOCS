# 04 — Dopesheet 时间线

## 界面

```
    0s     1s     2s     3s     4s     5s
    |      |      |      |      |      |
Position ──◆──────────◆──────────◆──────
Rotation ──◆────◆─────◆────◆─────◆──────
Scale    ──◆──────────◆──────────◆──────
          ▲                          ▲
    红色播放头                    关键帧菱形
```

## 关键帧操作

| 操作 | 方法 |
|------|------|
| 创建 | +Key / ●REC 自动 |
| 拖拽移动 | 按住菱形 ◆ 左右拖 |
| 删除 | 右键菱形 ◆ |
| 点击时间轴 | 跳转到该时间 |

## 洋葱皮

拖动时间滑块时自动高亮：
- 🔴 **粉色菱形** = 前一个关键帧
- 🔵 **蓝色菱形** = 后一个关键帧
- ⚪ 灰色 = 其他关键帧
- 🟠 橙色 = 选中属性的关键帧

前后帧菱形稍大（12px）并有白色边框。

## 红色播放头

跟随 `CurrentTime` 移动。可拖时间滑块或点击 Dopesheet 来移动。

## PPS 常量

`PPS = 80`（每 80 像素 = 1 秒）。时间刻度每秒标记一次。
