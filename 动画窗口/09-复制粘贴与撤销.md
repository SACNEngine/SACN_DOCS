# 09 — 复制粘贴与撤销

## 复制粘贴关键帧

| 操作 | 快捷键 | 行为 |
|------|--------|------|
| 复制 | **Ctrl+C** | 选中属性 → 复制该属性所有关键帧 |
| 复制（全部） | Ctrl+C（无选中属性时） | 复制全部属性的所有关键帧 |
| 粘贴 | **Ctrl+V** | 偏移到当前时间位置粘贴 |

### 粘贴逻辑

```
剪切板: [{t:0, v1}, {t:1, v2}, {t:2, v3}]
最小时间 = 0
当前时间 = 3.5
偏移量 = 3.5 - 0 = 3.5

粘贴结果:
  {t:3.5, v1}, {t:4.5, v2}, {t:5.5, v3}
```

## 撤销/重做

| 按钮 | 功能 |
|------|------|
| ↩ | 撤销（最多 50 步） |
| ↪ | 重做 |

### 实现

每次关键帧操作前序列化完整状态（JSON），存入 Undo 栈。撤销时恢复上一个快照。

覆盖的操作：
- +Key 添加关键帧
- Dopesheet 拖拽/删除
- 曲线编辑器添加/删除/拖拽
- +Evt 添加事件 / 删除事件
- Ctrl+V 粘贴

### 注意

独立于 Stride 全局 `IUndoRedoService`。不影响场景编辑的 Undo。
