# 02 — 可视化编辑器

## 打开编辑器

双击 `.sdctrl` 文件即可打开可视化状态机编辑器。也可以在属性面板点击 "Open this asset in editor"。

## 布局

```
┌─ Toolbar: [+ State] [+ Param] [Del] ──────────┐
│                                                 │
│  Entry ◉────(绿色虚线)────▶┌──────┐            │
│                             │ Idle │────▶┌────┐ │
│  Any State                  └──────┘     │Walk│ │
│                             ┌──────┐     └────┘ │
│                             │ Jump │           │
│                             └──────┘           │
│                                                 │
├─ Params: [Speed(Float)✕] [Jump(Trigger)✕] [+] ─┤
├─ State: Idle  Speed: 1.0 ──────────────────────┤
├─ Transition: Idle→Walk  [+Cond] ───────────────┤
└─────────────────────────────────────────────────┘
```

## 操作速查

| 操作 | 方式 |
|------|------|
| **创建状态** | 工具栏 `+ State` 或右键画布 → Add State |
| **移动状态** | 左键按住状态节点，拖动到目标位置 |
| **重命名状态** | **双击**状态节点 → 输入名称 → Enter 确认 |
| **选中状态** | 单击状态节点（Ctrl+点击多选） |
| **删除状态** | 选中 → `Delete` 键 |
| **创建过渡** | **右键**源状态 → Make Transition → 点击目标状态 |
| **删除过渡** | **右键**过渡箭头 |
| **Any State 过渡** | **右键** Any State 节点 → 点击目标状态 |
| **设为默认状态** | **右键**状态 → Set as Default State（绿色边框+入口箭头） |
| **缩放画布** | **鼠标滚轮**（0.2x ~ 5.0x） |
| **平移画布** | **鼠标中键按住拖动** |
| **取消操作** | `Esc` 键 |

## 参数面板

底部栏 `Params:` 区域：

- `+` 按钮：添加新参数（默认 Float 类型，名为 `P1`, `P2`...）
- `✕` 按钮：删除参数
- 参数名可点击后在属性面板中编辑类型和默认值

## 过渡条件编辑器

1. **点击**过渡箭头选中
2. 底部栏显示过渡信息：`Idle → Walk  Duration: 0.25s  ExitTime: 0.75`
3. 点击 `+Cond` 添加条件
4. 每个条件可配置：
   - **参数下拉**：选择绑定的参数
   - **模式下拉**：Greater / Less / Equals / NotEqual / If / IfNot
   - **阈值输入**：Float 比较值
   - **✕ 按钮**：删除条件

## 状态属性

点击状态节点后，底部栏显示：
- `State: Idle  Speed: 1.0  Motion: (none)`
- Speed 可在属性面板中修改

## 选中状态的视觉反馈

| 状态 | 边框效果 |
|------|---------|
| 默认状态 | **绿色边框** + Entry 箭头指向 |
| 选中状态 | **蓝色粗边框** |
| 过渡源状态 | **橙色边框**（Make Transition 模式下） |
| 普通状态 | 灰色边框 |

## 文件保存

- 所有操作通过 **Undo/Redo** 支持（Ctrl+Z / Ctrl+Y）
- **Ctrl+S** 保存到 `.sdctrl` YAML 文件
- 关闭重开项目，编辑内容保留

## 新功能 (2026-07)

### 过渡条件标签
连线中间显示条件摘要文字（如 `Speed > 0.5, IsRunning == true`）。

### Motion 类型选择
底部栏下拉框：`(none)/AnimationClip/BlendTree1D/BlendTree2D/BlendTreeDirect`。

### BlendTree1D/2D 可视化面板
选中 BlendTree 状态时，底部出现可视化混合空间编辑器。

### 多层切换
工具栏 ◀ ▶ 切换层 / +Layer 添加新层。

### Entry 节点右键菜单
点击 Entry → 弹出所有状态列表 → 选择默认入口状态。

### 复制粘贴状态
工具栏 📋 📄 按钮复制/粘贴状态节点。
