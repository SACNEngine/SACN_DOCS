# 01 — Animation Window System Overview

## Architecture

```
AnimationWindow (WPF UserControl)
├── ViewModel (AnimationWindowViewModel)
│   ├── AnimationClipBuilder → curve data
│   ├── DispatcherTimer → playback control
│   ├── Undo Stack → undo/redo
│   └── Save/Load → .sdanimclip asset
├── Dopesheet (Canvas) → timeline + keyframe diamonds
├── Curve Editor (Canvas) → multicolor sub-curves
└── Properties Panel → property list
```

## Data model

```
Animation Window data flow:
  entity Transform
       ↓ snapshot
  _kfv (Dictionary<string, Dictionary<float, object>>)
       ↓
  AnimationClipBuilder (_curves)
       ↓ Build()
  AnimationClipAsset
       ↓ AssetFileSerializer
  .sdanimclip (YAML asset)
       ↓ compiler
  AnimationClip → ContentManager → available at runtime
```

## Property paths (engine-compatible)

```
[TransformComponent.Key].Position   → AnimationCurve<Vector3>
[TransformComponent.Key].Rotation   → AnimationCurve<Quaternion>
[TransformComponent.Key].Scale      → AnimationCurve<Vector3>
```

Exactly matches the paths generated by the FBX importer.
