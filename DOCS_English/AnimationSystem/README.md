# Stride Animator System — Complete Documentation

## Overview

The Stride Animator System is a **state-machine-driven animation system**, comparable to the Unity Animator Controller (Mecanim).

### Core capabilities

- **State machine**: Visual animation states and transition logic
- **Blend trees**: 1D/2D parameterized blend spaces
- **Parameter system**: Float/Int/Bool/Trigger driven transitions
- **Layered animation**: Multiple independent state machines + AvatarMask bone masking
- **Animation events**: Timeline marker callbacks
- **State behaviours**: OnStateEnter/Exit/Update lifecycle
- **Override Controller**: Shared logic with swapped clips
